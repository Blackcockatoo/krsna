# Kṛṣṇapakṣi — The Fruit of Bhakti

Complete B$S literary edition, sixteen-movement English companion, interpretive commentary, source notes and ten devotional images. Responsive midnight-blue and weathered-gold reading experience.

## Deploy to Vercel

Import `Blackcockatoo/krsna`, select branch `main`, keep Root Directory at the repository root and Framework Preset **Other**. The included `vercel.json` serves the root directly: no build command, dependencies, environment variables or backend required. Click Deploy.

## Local preview

Run `python3 -m http.server 8000` from the repository root and open http://localhost:8000.

## Contents

- `index.html`: complete, pre-rendered edition; reading works without JavaScript.
- `content/complete-edition.md`: preserved full source edition for download.
- `assets/images/`: all ten supplied images, optimized as WebP.
- `assets/app.js`: accessible image viewer.
- `assets/style.css`: responsive presentation and print layout.

The chant is preserved as supplied. Its hybrid devotional language and the original English companion are distinguished in the editorial notes. The source edition’s cipher descriptions are retained; an eight-by-twenty-five source table was not supplied and is not reconstructed here.
